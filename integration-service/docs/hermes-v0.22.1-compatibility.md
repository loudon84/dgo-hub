# Hermes v0.22.1 compatibility note

**Version evidence:** Hermes Agent v0.22.1 is user-reported as installed on another machine. The official release/tag exists, but the remote installed binary/build, Profile, and complete commit were not observed. The official v0.22.1 documentation describes remote Streamable HTTP MCP, Authorization headers, exact `tools.include` filtering, disabling resources/prompts, profile-scoped secret interpolation, and `/reload-mcp`. Two v0.22.1 docs disagree on registered tool-name prefixes; record names from the actual `tools/list` response.

**M4 handoff:** configure the target Profile to `/mcp/sales` with Bearer auth, five PRD-native tool names, and resources/prompts disabled. Keep the secret in the target Profile secret store; never place its value in this repository. Probe the actual Hermes build/Profile, MCP initialize and tools/list, authorized and unauthorized calls, and redacted trace before claiming M4 verified. No probe was run for this task; all connection/auth/Profile bindings remain absent and product M4 is blocked.
